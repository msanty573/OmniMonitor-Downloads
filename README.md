# MJSMonitor downloads — the old address

**MJSMonitor** was called **OmniMonitor** until November 2026. This repository exists only to keep the old address
working for copies installed before the rename: their update files and their Linux package repositories
(apt and dnf) are still served from here.

- **Get MJSMonitor:** https://mjsapps.net/mjsmonitor/
- **Downloads:** https://github.com/msanty573/MJSMonitor-Downloads/releases/tag/latest
- **Linux package repositories** (new installs use these): https://msanty573.github.io/MJSMonitor-Downloads/

Nothing here needs your attention. Copies of MJSMonitor and OmniMonitor keep updating by themselves.
